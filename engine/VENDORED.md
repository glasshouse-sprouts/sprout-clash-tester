# Vendored from Clashero

This `engine/` folder started as a **copy** of the `clash/` folder from the
[Clashero](https://github.com/bruadam/clashero) project — the foundation
our engine is built on, credited in the README and `NOTICE`. There is no
submodule, no symlink, no automatic upstream tracking: we maintain the copy
here ourselves.

## What was excluded from the copy

- `target/` — Rust build artefacts (regenerated by `cargo build`).
- `.junie/` — IDE / AI agent memory files specific to the Clashero workflow.
- `.git/` — the source repo's history.

Everything else (`Cargo.toml`, `Cargo.lock`, `src/`, `tests/`, source
`.gitignore`) was copied verbatim.

## Policy from here on

- Bug fixes go directly into this folder. We do not push them upstream.
- We do not pull updates from upstream automatically. If something useful
  happens in Clashero in the future and we want it, the change is
  cherry-picked by hand, documented in this file, and tested.
- New engine features for this project (translation override, AABB-overlap
  sanity warning — see docs/HOW-IT-WORKS.md#placement-checks) are implemented here.
